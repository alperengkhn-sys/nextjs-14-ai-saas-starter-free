## 🛠️ Quick Setup (Free UI)

1. Clone the repository:
   git clone https://github.com/alperengkhn-sys/nextjs-14-ai-saas-starter-free.git
   cd nextjs-14-ai-saas-starter-free

2. Install dependencies:
   npm install

3. Run development server:
   npm run dev

Open http://localhost:3000 with your browser to see the result.
